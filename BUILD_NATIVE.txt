⚠️ SIGNING CONFIGURATION (For Release Build)
═════════════════════════════════════════════════════════════════════════════

For release builds (APK and AAB), you need a signing key.

Create signing key (one-time):
  keytool -genkey -v -keystore ~/daily-curiosity.keystore \
    -keyalg RSA -keysize 2048 -validity 10000 \
    -alias daily-curiosity-key

Configure in android/gradle.properties:
  MYAPP_RELEASE_STORE_FILE=../../daily-curiosity.keystore
  MYAPP_RELEASE_STORE_PASSWORD=your_password
  MYAPP_RELEASE_KEY_ALIAS=daily-curiosity-key
  MYAPP_RELEASE_KEY_PASSWORD=your_password

Then build release:
  ./build-native.sh

🎓 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: "Gradle not found"
Solution: 
  export ANDROID_HOME=~/Android/Sdk
  export PATH=$ANDROID_HOME/cmdline-tools/latest/bin:$PATH

Problem: "Java not found"
Solution: Install JDK 11+
  https://www.oracle.com/java/technologies/downloads/

Problem: Build fails
Solution:
  cd android
  ./gradlew clean
  cd ..
  npm run build
  npx cap sync android
  cd android
  ./gradlew assembleDebug

Problem: "Cannot find module" error
Solution:
  npm install
  npm run build
